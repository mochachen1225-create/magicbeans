# 傑克與魔豆 🫘

一款手機直式、單手就能玩的網頁小遊戲。種下魔豆、躲過拿掃把追出來的媽媽（因為傑克把家裡的牛牛換成豆子了），一路爬上雲端，再跟巨人玩「一二三木頭人」，從城堡偷走金蛋！一輪大約 30～60 秒，看誰最快。

**立即遊玩：** https://mochachen1225-create.github.io/magicbeans/

畫面是瓦楞紙手作風：紙板、紙膠帶、圖釘、毛氈，全部用程式即時畫出來。

## 怎麼玩

1. **種豆**：點一下土地，魔豆咻一聲長到雲端。
2. **爬藤**：魔豆有左、中、右三根藤。點傑克所在的那一根，點一下爬一步，只能往上不能往下。
   - 爬太慢會被媽媽追上：她越爬越快，落後太多還會衝刺；還沒破過關前會稍微慢一點。
   - 點太快會滑手（看下方的速度條）。
3. **換藤**：點**別根藤**，傑克就直接跳過去（左跳到右也行），用來閃避障礙。
4. **大風**：按住螢幕不要動，撐過去。
5. **巨人家（一二三木頭人）**：巨大的紙偶巨人從城堡後面探出頭。
   - 他用手指摀住眼睛唸口訣時，**按住**前進。
   - 手一放下、眼睛盯著你，就馬上**放開**。
   - 溜進門拿到金蛋就過關。口訣每個字配一個音，越唸越快就代表他快轉頭了；被盯著時會聽到心跳聲。

電腦也能玩：用滑鼠點擊、按住。

## 結算、稱號與分享

抵達後依完成秒數給傑克一個稱號，再依表現加上小徽章：

- **稱號**：閃電魔豆王（< 32 秒）、雲端飛毛腿（< 40 秒）、金蛋神偷（< 50 秒）、勇敢的爬藤少年（< 65 秒）、慢慢爬也是英雄
- **徽章**：毫髮無傷、金幣收藏家、熱氣球冒險家、木頭人大師、掃把下逃生、手滑大王

最佳紀錄只存在自己的瀏覽器裡（localStorage），不會上傳。按「分享成績」會先預覽成績卡圖片（秒數＋稱號），再選：

- 分享圖片＋分數（可選 LINE）
- 儲存圖片（也可以長按圖片儲存）
- 只分享文字

小提醒：在 LINE 或 Facebook 裡直接點開連結時，分享圖片有時不順，用 Safari 或 Chrome 打開最穩。

## 技術說明

- 遊戲本體是單一 `index.html`，不需要伺服器、資料庫或 AI，打開就能玩。
- 操作用 Pointer Events，手指和滑鼠都適用；支援的手機有震動回饋（Vibration API）。
- 部署：GitHub Pages（Settings → Pages → Deploy from a branch）。
- 開發紀錄、設計決定和還沒做的點子寫在 [NOTES.md](NOTES.md)。

## 本機執行

直接用瀏覽器打開 `index.html` 就能玩（字型需要網路，沒網路時會用系統字型）。
