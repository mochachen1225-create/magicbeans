# 傑克與魔豆 🫘

一款手機直式、單手就能玩的網頁小遊戲。種下魔豆、躲過拿掃把的媽媽，一路爬上雲端，從巨人的城堡偷走金蛋！一輪大約 30～60 秒。

**立即遊玩：** https://mochachen1225-create.github.io/magicbeans/

## 怎麼玩

1. **種豆**：點一下土地，魔豆咻一聲長到雲端。
2. **爬藤**：魔豆有左、中、右三根藤。點傑克所在的那一根，點一下爬一步，只能往上不能往下。爬太慢會被媽媽追上，點太快會滑手。
3. **換藤**：點**別根藤**，傑克就直接跳過去（左跳到右也行），用來閃避障礙。
4. **大風**：按住螢幕不要動，撐過去。
5. **巨人家（一二三木頭人）**：巨人背對時按住前進，一轉頭就馬上放開。溜進門拿到金蛋就過關。

電腦也能玩：用滑鼠點擊、按住。

## 結算與稱號

抵達後會依完成秒數給傑克一個稱號，再依表現加上小徽章：

- 稱號：閃電魔豆王（< 32 秒）、雲端飛毛腿（< 40 秒）、金蛋神偷（< 50 秒）、勇敢的爬藤少年（< 65 秒）、慢慢爬也是英雄
- 徽章：毫髮無傷、金幣收藏家、熱氣球冒險家、木頭人大師、掃把下逃生、手滑大王

最佳紀錄存在瀏覽器（localStorage）。按「分享成績」會先預覽成績卡圖片（秒數＋稱號），再選擇：分享圖片＋分數（可選 LINE）、儲存圖片（也可長按圖片儲存）、或只分享文字。

## 技術說明

- 單一 `index.html`，沒有外部圖片、函式庫、伺服器或 AI：畫面用 Canvas 2D 即時繪製（瓦楞紙手作風：紙板、紙膠帶、圖釘、毛氈），音效用 Web Audio 合成，震動用 Vibration API。
- 操作用 Pointer Events，手指和滑鼠都適用。
- 部署：GitHub Pages（Settings → Pages → Deploy from a branch）。

## 本機執行

直接用瀏覽器打開 `index.html` 就能玩。
